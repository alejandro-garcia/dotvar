# Service logo sources

The original SVGs come from [SVGL's public catalog](https://api.svgl.app). [`manifest.json`](manifest.json) records the source, Rust variant, geometry, and SHA-256 for each original. [`service_logos.rs`](../../src/service_logos.rs) declares the catalog used by the app.

Dotvar embeds [monochrome derivatives](monochrome/README.md) and applies the color associated with the current environment file. The original SVGs are retained for provenance. See the [SVGL license](LICENSE.svgl) and [third-party notices](../../../../THIRD_PARTY_NOTICES.md) for attribution.
